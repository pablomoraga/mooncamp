# Moon Camp

Proyecto STEAM de robótica, diseño 3D y programación creado en el **Club Robótica Granada**. Incluye dos misiones:

- **ESEROver**: un rover de exploración basado en Cutebot con placa micro:STEAMakers, con retos de programación («Destino Marte») y control IoT por MQTT.
- **Moon Garden**: un huerto lunar con sensores para medir y controlar temperatura, humedad, riego y luz.

[![Abrir el recurso](https://img.shields.io/badge/▶_Abrir_el_recurso-2ea44f?style=for-the-badge)](https://pablomoraga.github.io/mooncamp/)

## Contenido
- Objetivos del proyecto
- ESEROver Cutebot: estructura, piezas STL, placa de control y biblioteca
- Retos Cutebot «Destino Marte»: desplazamiento sobre planeta, parada en blanco, robot mágico, esquiva rocas, encerrado, siguelíneas y control remoto
- ESEROver IoT: MQTT, brokers, placa IoT, paneles y control wifi
- Moon Garden: hardware, conexionado, estructura, software y retos
- Evaluación del proyecto y actividades en el aula
